Introduction

My-Pety is an AI-powered desktop pet and personal assistant built with Rust and Tauri. It can chat, search the web, remember information, open websites, manage reminders, and assist with everyday tasks.

My-Pety is currently in active development, and some features are still experimental. Thank you for your patience and support while the project grows.

Features

  • AI chat assistant
  • Open web search using command
  • Web search with browser for latest information
  • Real time lookup for latest information
  • File reading and summarization
  • Running applications viewer
  • System information viewer
  • Memory system (important for context)
  • Password protection
  • Reminder system
  • First time setup configuration
  • Animation desktop pet friend
  • Custom cursor support
  • Dragging desktop window support
  • Transparent window support

Manual & Commands

Type these commands directly into the chat input to control the pet or your system:

  • time — Show current time
  • search rust — Search the web for latest info
  • open youtube — Open any website in your browser
  • read notes.txt — Read and summarize a local file
  • system info — Show RAM and system memory usage
  • open apps — List currently running applications
  • open app notepad — Open any desktop app (e.g. notepad, calc, mspaint)
  • volume 50 — Set master system volume (0-100)
  • brightness 60 — Set system screen brightness (0-100)
  • battery — Show your current battery charge status
  • screen or screenshot — Capture your desktop and analyze it with AI vision
  • remember hobby = coding — Save key-value facts into memory
  • show memories — View all saved memories
  • favorite language — Recall saved favorite language memory
  • remind me 60 study rust — Create a reminder timer in seconds
  • close — Close the My-Pety application
