# My-Pety

Lightweight desktop pet built with Rust and Tauri.

## What it does

- Opens as a small floating window
- Stays on top of other windows
- Has a transparent background
- Can be dragged with the mouse from anywhere on the pet
- Shows the `moxi-idle.gif` pet animation
- Uses one small HTML file for the pet UI

## Run

```powershell
cd src-tauri
cargo run
```
